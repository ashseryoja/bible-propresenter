# Шрифты

`Montserratarm-Regular.woff`, `Montserratarm-Medium.woff`, `Montserratarm-SemiBold.woff` — Montserrat Arm: шрифт Montserrat
(Julieta Ulanovsky) с армянскими буквами Ваана Ованнисяна (Vahan Hovhannisyan). Лицензия SIL Open Font License 1.1
(`OFL.txt`), она же записана внутри самих файлов. Взяты из репозитория автора https://github.com/vahanhovh/montserrat-arm.
Подключаются в `css/app.css` (`@font-face`, семейство «Montserrat Arm»); шрифт для чтения выбирается в меню «⋯ → Шрифт».
