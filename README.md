# Библия «Հին Արարատ» — просмотр, правка и экспорт для ProPresenter

Страница, на которой можно читать Библию (66 книг, 1189 глав, 31 097 стихов), править стихи и скачать
готовые `bible.db3` + `rvmetadata.xml` для ProPresenter одним `.zip`. Интерфейс на русском; сделан в первую
очередь для телефона, на планшете и компьютере тоже удобен.

## Как пользоваться

- Название вверху (например «Սաղմոս 23») открывает список книг и глав. Можно набрать ссылку:
  «Ин 3:16», «Быт 1», «Հով 3:16». Русское «Псалом 22» переводится в нумерацию этой Библии (Псалом 23).
- Нажмите на стих: «Править», «Копировать», «Ещё» (вставить новый стих после, объединить со следующим,
  разделить, перенести в соседнюю главу, удалить, вернуть исходный текст).
- После каждой правки внизу появляется «Отменить». Есть и «Отменить последнее» в меню «⋯».
- Значок с файлом вверху → «Правки и экспорт»: список изменений (было / стало), кнопка
  **«Скачать для ProPresenter (.zip)»**, копия правок (.json), названия книг, «Сбросить все правки».
- Поиск не зависит от орфографии («Աստված» находит «Աստուած»). «Найти и заменить» ищет точное совпадение
  и перед заменой показывает все места.

## Установка в ProPresenter

Архив содержит `bible.db3`, `rvmetadata.xml` и `README.txt` с инструкцией. Файлы заменяют файлы
установленной Библии «A Conservative Version» (ACV) — поэтому сокращение ACV в параметрах экспорта
оставляют как есть.

## Запуск

Локально: откройте `index.html` в браузере (работает и с `file://`; шрифты подгружаются из интернета,
без него страница использует системные). Правки хранятся в этом браузере (IndexedDB).
Выложить на свой сайт: скопируйте папку целиком на любой статический хостинг.

С небольшим сервером:

```bash
python3 -m http.server 8137 --directory ararat-site
```

## Устройство

| Файл | Что делает |
| --- | --- |
| `data/`, `tools/make_data.py` | текст всех книг (берётся из `../ararat-old/bible.db3`) |
| `js/sqlite-writer.js`, `js/zip.js`, `js/exporter.js` | пишут `bible.db3` (чистый JS, без библиотек) и zip |
| `js/fold.js` | сравнение слов без учёта орфографии, регистра и знаков |
| `js/data.js` | текст в памяти, правки, отмена, разделение / объединение / перенос стихов |
| `js/store.js`, `js/platform.js` | где хранятся правки и как сохраняются файлы (браузер или claude.ai) |
| `js/i18n.js`, `js/refs.js` | строки интерфейса (ключ = русский текст), разбор ссылок, нумерация псалмов |
| `js/ui.js`, `js/view-*.js`, `js/app.js`, `css/app.css`, `index.html` | интерфейс |
| `tools/build_artifact.py` | собирает версию для claude.ai (`dist/artifact.html`) |

Чтобы добавить армянский интерфейс: `AB.i18n.addDict('hy', {'Править': 'Խմբագրել', …})` и
`AB.i18n.setLang('hy')`; остальной код менять не нужно.

## Проверки

```bash
node tests/test-fold.js
node tests/test-data.js
node tests/test-refs.js
node tests/test-export.js OUT_DIR && python3 tests/validate_db.py OUT_DIR   # настоящий SQLite открывает результат
```

Версия для claude.ai: `python3 tools/build_artifact.py`, затем `dist/host-test/index.html` (страница с
подделкой `window.claude`, файл `tests/host-mock.js`) — для проверки сохранения через `db` и скачивания через
`downloads` без публикации.

## Версия для claude.ai

Один HTML-фрагмент (`dist/artifact.html`) + 66 файлов `data/bNN.json`. Правки хранятся в приватной области
пользователя (`db` + `user`), скачивание идёт через capability `downloads` (пользователь подтверждает
сохранение), тема берётся из настроек claude.ai.
