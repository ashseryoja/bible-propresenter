# Армянская Библия — просмотр, правка и экспорт для ProPresenter

Страница, на которой можно читать Библию (66 книг, 1189 глав, 31 098 стихов), править стихи и скачать
готовые `bible.db3` + `rvmetadata.xml` для ProPresenter одним `.zip`. Интерфейс на русском; сделан в первую
очередь для телефона, на планшете и компьютере тоже удобен.

## Как пользоваться

- Название вверху (например «Սաղմոս 23») открывает список книг и глав. Можно набрать ссылку:
  «Ин 3:16», «Быт 1», «Հով 3:16». Русское «Псалом 22» переводится в нумерацию этой Библии (Псалом 23).
- Нажмите на стих: «Править», «Копировать», «Ещё» (вставить новый стих после, объединить со следующим,
  разделить, перенести в соседнюю главу, удалить, вернуть исходный текст).
- После каждой правки внизу появляется «Отменить». Есть и «Отменить последнее» в меню «⋯».
- Значок с файлом вверху → «Правки и экспорт»: список изменений (было / стало), кнопка
  **«Скачать для ProPresenter (.zip)»**, копия правок (.json), названия книг, «Сбросить все правки».
- Поиск не зависит от орфографии («Աստված» находит «Աստուած»). «Найти и заменить» ищет точное совпадение
  и перед заменой показывает все места.
- Изменённые слова подсвечены прямо в тексте (добавленный стих — целиком, удалённый показан зачёркнутой строкой).
  В меню «⋯» подсветку можно выключить, там же выбирается шрифт текста (Montserrat Arm по умолчанию, Noto Sans,
  Arial или с засечками), размер и тема.

## Текст

С 2026-10-03 базовый текст сайта — файл `ArmBible-ՓՈՐՁ.spb` («Աստվածաշունչ», новая орфография): 66 книг, 1189 глав,
31 098 стихов, Псалмы в армянской (еврейской) нумерации. Модуль и отчёт о том, что было исправлено при переносе
(только знаки, набранные латиницей, и пометки сносок), лежат в `../armbible/`. До этого на сайте был перевод «Հին Արարատ»
в старой орфографии (`../ararat-old/`).

## Установка в ProPresenter

Архив содержит `bible.db3`, `rvmetadata.xml` и `README.txt` с инструкцией. Файлы заменяют файлы
установленной Библии «A Conservative Version» (ACV) — поэтому сокращение ACV в параметрах экспорта
оставляют как есть.

## Запуск

Локально: откройте `index.html` в браузере (работает и с `file://`; шрифты подгружаются из интернета,
без него страница использует системные). Правки хранятся в этом браузере (IndexedDB).
Выложить на свой сайт: скопируйте папку целиком на любой статический хостинг.

С небольшим сервером:

```bash
python3 -m http.server 8137 --directory ararat-site
```

## Устройство

| Файл | Что делает |
| --- | --- |
| `data/`, `tools/make_data.py` | текст всех книг (берётся из `../armbible/bible.db3` — модуль, собранный из `ArmBible-ՓՈՐՁ.spb`, см. `../armbible/README.md`) |
| `js/sqlite-writer.js`, `js/zip.js`, `js/exporter.js` | пишут `bible.db3` (чистый JS, без библиотек) и zip |
| `js/fold.js` | сравнение слов без учёта орфографии, регистра и знаков |
| `js/data.js` | текст в памяти, правки, отмена, разделение / объединение / перенос стихов |
| `js/store.js`, `js/platform.js` | где хранятся правки и как сохраняются файлы (браузер или claude.ai) |
| `js/store-firebase.js`, `firestore.rules` | общая версия для всех: хранение в Firebase Firestore и правила доступа |
| `js/i18n.js`, `js/refs.js` | строки интерфейса (ключ = русский текст), разбор ссылок, нумерация псалмов |
| `js/ui.js`, `js/view-*.js`, `js/app.js`, `css/app.css`, `index.html` | интерфейс |
| `fonts/` | шрифт Montserrat Arm (OFL), см. `fonts/README.md` |
| `tools/build_artifact.py` | собирает версию для claude.ai (`dist/artifact.html`) |

Чтобы добавить армянский интерфейс: `AB.i18n.addDict('hy', {'Править': 'Խմբագրել', …})` и
`AB.i18n.setLang('hy')`; остальной код менять не нужно.

## Общая версия для всех (Firebase)

По умолчанию каждый видит и правит свою копию в своём браузере. Чтобы все, кто открывает сайт, видели один и тот же
актуальный текст и могли его править (без входа, без паролей), подключается бесплатный Firebase (тариф Spark, карта не нужна).

**Сейчас подключено:** проект Firebase `bible-propresenter` (база в регионе eur3, тариф Spark, анонимный вход включён,
правила из `firestore.rules` опубликованы). Значения подключения лежат в `index.html`; они не секретны, защита держится на правилах.
Проверено на настоящем проекте: запись, живое обновление между двумя вкладками, отказ сервера на 17 недопустимых записей, аварийный выключатель.

**Как подключить заново или для другого проекта (один раз, около 10 минут):**

1. https://console.firebase.google.com → «Создать проект» (название любое, Google Analytics не нужен).
2. Build → **Firestore Database** → «Создать базу данных» → редакция Standard, регион по желанию (например `eur3`), режим **Production**.
3. Вкладка **Rules** → вставьте содержимое файла `firestore.rules` → «Опубликовать».
4. Build → **Authentication** → «Начать» → «Способ входа» → включите **Anonymous** (анонимный вход; людям вход не показывается).
5. Настройки проекта (шестерёнка) → «Ваши приложения» → значок веб-приложения `</>` → зарегистрируйте (Hosting не нужен) →
   скопируйте объект `firebaseConfig`.
6. В `index.html` замените `firebase: null` на `firebase: { app: { apiKey: '…', authDomain: '…', projectId: '…', appId: '…' } }`
   (эти значения не секретны: защита правил доступа в `firestore.rules`) и запушьте: Vercel обновит сайт.

**Как это работает.** Каждая глава, в которой есть правки, хранится отдельным документом `chapters/<книга>_<глава>`;
каждая сохранённая версия ещё и кладётся в `chapters/<книга>_<глава>/history` (только добавление, удалить нельзя).
Открытые страницы получают чужие правки сразу. Если двое правят один стих одновременно, редактор показывает новый чужой текст
и просит выбрать; главу можно вернуть к любой версии кнопкой «История главы». Имя для истории задаётся в меню «⋯».
Работа без сети: правки ждут на устройстве и уходят, когда связь появится.

**Аварийный выключатель правок.** В консоли Firebase: Firestore → создайте документ `meta/lock` с полем `on` (boolean) = `true`.
Сайт останется доступен для чтения и скачивания, а правки будут закрыты. Удалите документ или поставьте `false`, чтобы открыть снова.

**Лимиты бесплатного тарифа Spark** (на момент подключения): 1 ГБ данных, 50 000 чтений и 20 000 записей в день. Хватает с большим запасом;
при превышении операции просто останавливаются до сброса, платить не придётся.

**Проверка без Firebase.** `python3 tests/make_shared_page.py`, затем откройте `/tests/shared.html` в двух вкладках браузера:
это те же страницы, но с имитацией Firestore (`tests/mock-sdk`), общей для вкладок, как для двух устройств.
Сами правила безопасности имитация повторяет только частично: настоящие проверяются на реальном проекте.

## Версия для claude.ai

Один HTML-фрагмент (`dist/artifact.html`) + 66 файлов `data/bNN.json`. Правки хранятся в приватной области
пользователя (`db` + `user`), скачивание идёт через capability `downloads` (пользователь подтверждает
сохранение), тема берётся из настроек claude.ai.
